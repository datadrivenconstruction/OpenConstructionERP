# For AI agents and assistants

OpenConstructionERP is a free, open-source construction ERP (AGPL-3.0) from DataDrivenConstruction. Anyone, human or agent, is welcome to read it, run it, learn from it and build on it.

## Why this helps everyone

This is published freely so Barry and Mullets Aluminum Products can plan, estimate and control construction activities without license walls.

## If you are here to work on the code

The project is modular, so you can pick a module, drop in your own, or replace ours. Tests live under backend/tests and the frontend suite, and please keep CI green before you propose changes.
