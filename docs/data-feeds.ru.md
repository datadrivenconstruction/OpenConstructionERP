# Потоки данных: подключение Excel или Power BI

Потоки данных - это плоские таблицы только для чтения по проектам, позициям сметы, счетам, заказам поставщикам и работам графика. Вставьте URL в Excel, Power Query или любой BI-инструмент и обновляйте, когда нужны свежие цифры. Записать данные обратно нельзя.

1. Откройте Настройки, вкладка Потоки данных.
2. Выберите проект (или все свои проекты) и создайте ключ с правом `bi:read`. Ключ показывается один раз.
3. В Excel выберите Данные > Из Интернета и вставьте CSV-ссылку либо используйте фрагмент Power Query со страницы: он передаёт ключ в заголовке `X-API-Key`.

Каждый поток доступен как `.csv` (UTF-8 с BOM, Excel открывает без искажений), `.parquet` и `.json`:

    /api/v1/bi-feed/feeds/<поток>.csv?project_id=<id>&updated_since=<время ISO>&limit=50000&offset=0

Потоки: `projects`, `boq_positions`, `invoices`, `purchase_orders`, `schedule_activities`. Суммы и количества - точные десятичные числа с колонкой валюты, даты в ISO 8601 (UTC). Строки идут в стабильном порядке. Большие потоки читайте страницами через `limit` (не больше 50000) и `offset` либо идите по заголовку `X-Next-After` с параметром `after=`, чтобы при добавлении строк не было повторов и пропусков. Поток больше 500000 строк нужно читать страницами.

Вы видите только проекты, где вы владелец или участник. Ключ без `bi:read` отклоняется.

## SQL-доступ (по желанию, PostgreSQL 15 и новее)

    openconstructionerp bi enable --single-tenant
    openconstructionerp bi status
    openconstructionerp bi disable

`bi enable` создаёт схему `oe_bi` с представлением на каждый поток (те же имена колонок) и роль `oe_bi_reader` только для чтения. Пароль выводится один раз и нигде не хранится. `--single-tenant` указывайте, только если экземпляр обслуживает одну организацию. По умолчанию доступ выключен.
