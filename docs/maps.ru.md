# Карты, съёмки объекта

## Съёмки объекта

На карте Geo Hub кнопка **Съёмки** принимает ортофотоплан с дрона (GeoTIFF) с датой полёта или привязывает уже
загруженный скан. Изображение встаёт на глобус по собственным координатам. Выберите съёмку, введите наблюдаемый процент
выполнения по каждой работе графика, и таблица покажет его рядом с плановым прогрессом на эту дату. Числа вводит
человек, автоматических оценок нет.
