# Karten, Standortaufnahmen

## Standortaufnahmen

In der Geo-Hub-Karte nimmt **Aufnahmen** ein Drohnen-Orthofoto (GeoTIFF) mit Flugdatum entgegen oder verknuepft einen
bereits hochgeladenen Scan. Das Bild wird anhand seiner eigenen Koordinaten auf dem Globus platziert. Waehlen Sie eine
Aufnahme, tragen Sie den beobachteten Fertigstellungsgrad je Terminplanvorgang ein, und die Tabelle zeigt ihn neben dem
geplanten Fortschritt zum Stichtag. Die Werte tragen Menschen ein; es wird nichts automatisch geschaetzt.
