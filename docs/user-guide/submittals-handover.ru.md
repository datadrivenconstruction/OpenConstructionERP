# Согласования: ответственный, рассылка и закрытие

Следите, кто должен действовать по согласованию следующим, кто получает копию и когда оно завершено.

Откройте **Документы > Согласования** и выберите согласование.

## Передать дальше

1. В разделе **Ответственный и рассылка** выберите в поле **Ball in court** того, кто должен действовать следующим. Меняйте его, когда вопрос переходит к другому человеку.
2. Добавьте в **Список рассылки** всех, кто должен получить согласование для сведения. На карточке он показан как "Рассылка: имена".
3. Когда по согласованию принято решение (утверждено, утверждено с замечаниями или отклонено), закройте его кнопкой **Закрыть**. Закрывать могут роли, которым разрешено изменять согласования.

Выбрать можно только тех, кто может открыть проект.

## О чём предупреждают правила проверки

- `submittal.ball_in_court_assigned`: у открытого согласования нет ответственного.
- `submittal.distribution_present`: у открытого согласования пустой список рассылки.
- `submittal.people_have_project_access`: ошибка, если ответственный или адресат рассылки не может открыть проект.
