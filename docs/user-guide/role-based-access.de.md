# Rollen: Nicht verfügbare Aktionen nennen den Grund

Jede Rolle kann die Bildschirme ihres Projekts öffnen und lesen. Aktionen, die die Rolle nicht ausführen darf, bleiben sichtbar, sind aber deaktiviert, und der Tooltip nennt die nötige Rolle.

1. Öffnen Sie einen beliebigen Bildschirm, zum Beispiel eine Bestellung, das Kostenmodell oder ein Register.
2. Suchen Sie eine ausgegraute Schaltfläche oder ein ausgegrautes Feld. Fahren Sie darüber oder fokussieren Sie es: Der Tooltip sagt zum Beispiel, dass die Aktion Bearbeitern, Managern oder Administratoren vorbehalten ist.
3. Bitten Sie einen Projektadministrator um eine höhere Rolle oder lassen Sie den Schritt von jemandem mit dieser Rolle ausführen.

Dieselbe Regel gilt für schreibgeschützte Vorschauen: Eine Vorschau braucht nur das Leserecht, der Schritt, der die Änderung übernimmt, behält das Änderungsrecht. Nach dieser Regel arbeiten unter anderem Finanzen, Einkauf, Verträge, Geräte, Baugruppen, die Vorlagen und der Katalog des Leistungsverzeichnisses, Baustellenlogistik, der Vermessungsplan, Kollisionsprüfung und Buchhaltungs-Synchronisierung. Import-Schaltflächen zeigen den Pfeil in die Ablage, Export-Schaltflächen den Pfeil heraus, auf allen Bildschirmen.
