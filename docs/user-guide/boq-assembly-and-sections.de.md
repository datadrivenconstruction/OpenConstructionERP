# Baugruppe in eine Position einfügen und Abschnitte verschieben

Bepreisen Sie eine bestehende Position aus einer Baugruppe und ordnen Sie das Leistungsverzeichnis um, ohne Arbeit zu verlieren.

## Baugruppe einfügen

1. Öffnen Sie im Leistungsverzeichnis das Zeilenmenü einer Position und wählen Sie **Baugruppe einfügen**.
2. Wählen Sie die Baugruppe. Der Dialog listet ihre Bestandteile mit Menge, Preis und Betrag und zeigt den Preis der Position jetzt und nach der Änderung.
3. Stellen Sie bei Bedarf den **Mengenfaktor** ein. Er multipliziert jede Bestandteilsmenge, zum Beispiel 1,1 für 10 % Verschnitt.
4. Hat die Position bereits Ressourcen, wählen Sie **Ersetzen** oder **Baugruppe hinzufügen**. Ressourcen, die für die ganze Position eingetragen sind, lassen sich nur ersetzen.
5. Wählen Sie **In Position einfügen**. Nummer, Text und Menge bleiben; Ressourcen und Einheitspreis stammen aus der Baugruppe. Eine Meldung bietet **Rückgängig** an.

Der Dialog warnt, wenn die Einheit der Baugruppe von der der Position abweicht, wenn ihre Währung von der des Projekts abweicht und wenn die Baugruppe keine Bestandteile hat. In einem schreibgeschützten Leistungsverzeichnis wird die Aktion nicht angeboten.

## Abschnitte und Zeilen verschieben

Ziehen Sie einen Abschnitt oder eine Zeile an eine neue Stelle. Das gesamte Verzeichnis wird in der neuen Reihenfolge gespeichert, und ein Ablegen auf einer eingerückten Zeile setzt das Element neben den Abschnitt, der sie enthält. Ein verschobener Abschnitt springt also nicht mehr zurück.
