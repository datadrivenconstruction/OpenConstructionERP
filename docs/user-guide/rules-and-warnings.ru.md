# Правила для техники, бюджетного реестра и качества данных

Краткая справка по правилам, которые проявляются как ошибки или предупреждения. Предупреждения не блокируют работу; они показывают, что стоит поправить, пока это не обошлось дорого.

## Дополнительные пакеты

Базовая установка покрывает всё, кроме двух необязательных пакетов:

- `pip install "openconstructionerp[saml]"` добавляет единый вход SAML, см. [SSO](../sso.ru.md). Для OIDC ничего дополнительного не нужно.
- `pip install "openconstructionerp[parquet]"` добавляет `pyarrow` для Parquet-выгрузок, см. [потоки данных](../data-feeds.ru.md). Без него `.parquet`-поток отвечает понятным сообщением с названием этого пакета, а Настройки > Потоки данных скрывают Parquet-ссылку. CSV и JSON работают как обычно.

## Техника

- Каждая единица техники принадлежит одному тенанту (вашей организации). Другие тенанты её не видят.
- К проекту единица привязывается только через аренду с датами (начало и конец). Бессрочной привязки к проекту нет.
- Две аренды одной единицы, пересекающиеся по времени, отклоняются: машина не может в один день работать на двух проектах. Сократите или сдвиньте одну из аренд.

## Бюджетный реестр: разделение обязанностей

В настройках бюджетного реестра каждого проекта есть **Разделение обязанностей**, по умолчанию включено. Пока оно включено, тот, кто запросил перенос или изменение бюджета, не может сам его утвердить; нужен второй человек. Отключение требует права управления моделью затрат, фиксируется в журнале и подходит только очень маленьким командам.

## Предупреждения

- **Акт о несоответствии (NCR) закрыт без причины**: закрытие серьёзного NCR с пустой первопричиной даёт предупреждение. Заполните причину, чтобы корректирующее действие было прослеживаемо.
- **Страховка или гарантия без суммы покрытия**: полис или гарантия без суммы покрытия помечаются. Укажите сумму, чтобы отчёты по рискам были полными.
- **Расценка в смете без валюты**: расценка без валюты получает базовую валюту проекта и показывает предупреждение. Проверьте её: расценка в другой валюте иначе будет оценена неверно.

## Ссылки для доступа

Ссылка на файл скрывает имя файла и сведения о нём, пока посетитель не введёт пароль, а также после истечения срока ссылки. Без доступа или после истечения срока посетитель видит только нейтральный запрос или уведомление.

## Пакет США: залоговые права (liens)

Пакет США содержит законы о залоговых правах и уведомлениях по штатам только как справочную информацию. Сроки и формы меняются и зависят от договора, поэтому перед применением проверьте их с юристом.
