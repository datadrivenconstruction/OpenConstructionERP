# Subcontractor insurance certificates

Keep each subcontractor's insurance certificate on file and show who has checked it.

Open **Subcontractors**, then the subcontractor or its agreement.

1. Upload the insurance document with the agreement document upload. It registers a certificate on the subcontractor, marked **Awaiting review**.
2. A reviewer with the prequalification approval right opens the certificate list and uses **Mark as verified** after reading the file. **Withdraw verification** undoes it, and the file can be opened from the same row.
3. Replacing the file or changing the expiry date resets the review, so a verified mark always refers to the file and date you see.

Roles without the approval right see the review state but not the buttons. The subcontractor validation rules warn about missing and expired certificates.
