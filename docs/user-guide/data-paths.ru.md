# Пути данных

Посмотрите, откуда каждый модуль берёт данные и кто их использует.

Нажмите кнопку **Пути данных** вверху справа в любом модуле или откройте `/data-paths`.

1. **Вид модуля**: выберите модуль, чтобы увидеть его источники, сам модуль с параметрами, потребителей и подписанные связи между ними. Выберите связь, чтобы увидеть путь подробно.
2. **Трассировка поля**: выберите поле и проследите его от места ввода до каждого места, где оно читается.
3. **Карта платформы**: все модули по фазам проекта с подписанными связями между ними.

Тексты написаны простыми словами и доступны на каждом языке интерфейса. Разрыв на пути означает, что у следующего шага нет входных данных.
