# Datenpfade

Sehen Sie, woher jedes Modul seine Daten bekommt und wer sie nutzt.

Klicken Sie auf **Datenpfade** oben rechts in einem beliebigen Modul oder öffnen Sie `/data-paths`.

1. **Modulansicht**: Wählen Sie ein Modul, um seine Quellen, das Modul mit seinen Parametern, seine Abnehmer und die beschrifteten Verbindungen zu sehen. Eine Verbindung zeigt auf Klick den Pfad im Detail.
2. **Feldverfolgung**: Wählen Sie ein Feld und folgen Sie ihm von der Eingabe bis zu jeder Stelle, die es liest.
3. **Plattformkarte**: Alle Module nach Projektphase angeordnet, mit den beschrifteten Verbindungen dazwischen.

Die Texte sind in einfachen Worten geschrieben und in jeder Oberflächensprache verfügbar. Eine Lücke auf einem Pfad bedeutet, dass dem nächsten Schritt die Eingabe fehlt.
