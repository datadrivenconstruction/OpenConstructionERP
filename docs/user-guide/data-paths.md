# Data paths

See where each module gets its data and who uses it.

Click the **Data paths** button at the top right of any module, or open `/data-paths`.

1. **Module view**: pick a module to see its sources, the module with its parameters, its consumers and the labelled links between them. Select a link for the path detail.
2. **Field trace**: pick a field to follow it from where it is entered to every place that reads it.
3. **Platform map**: all modules arranged by project phase, with the labelled links between them.

Texts are written in plain words and are available in every interface language. A gap on a path means the next step has no input.
